# действия инспекторов

Сколько инспекторы могут просить друг у друга на одном
запросе. Что именно просят и как это читает получатель —
[inspector-actions.md](../../inspector-actions.md).

Действие едет в `prior` рядом с вердиктом того, кто его
высказал. Модуль его не исполняет: проверяет форму, переносит,
считает и пишет в аудит. Поэтому здесь только пределы.

```
waf_action_max  <size>;
waf_actions_max <n>;
```

Контекст: `http`, `server`, `location`, наследуемые. Переопределять запись и
архив маршрута глаголами `audit` / `archive` вправе любой инспектор,
спрошенный на маршруте: отдельного гранта нет
([inspector-actions.md](../../inspector-actions.md#запись-и-архив)).

```nginx
http {
    waf_action_max  192;
    waf_actions_max 16;

    location /api/ {
        waf_inspect request ip      wave=0 timeout=5ms;
        waf_inspect request modsec  wave=1 timeout=1000ms;
        waf_inspect request captcha wave=2 timeout=10ms;
    }

    location /static/ {
        waf_actions_max 0;          # переписываться некому
        waf_inspect request ip wave=0 timeout=5ms;
    }
}
```

# waf_action_max

Потолок одного действия с провода. Умолчание `192`.

Больше — действие отброшено со счётчиком, ответ цел. Это не
`waf_reply_max`: там половину разобрать нельзя, здесь можно —
вердикт самодостаточен, просьба к нему довесок.

# waf_actions_max

Сколько действий живёт на запросе. Умолчание `16`. Счёт общий
на все фазы: `prior` сквозной, действие фазы запроса занимает
место до конца запроса.

`0` — канал выключен на маршруте. С провода действия
отбрасываются, в `prior` не появляются, вердикты едут как
раньше.

Предел достигнут — отбрасываются новые, прежние остаются.
Вытеснять старые нельзя: болтливый инспектор стирал бы чужие
просьбы, и отказ получался бы тихим и чужим.

Оба предела нужны до запроса: буфер сообщения считается заранее,
одним `ngx_pnalloc`, и `prior` входит в бюджет как
`waf_actions_max × waf_action_max` плюс запись на инспектора
на каждую пройденную фазу.

# правила

- `waf_actions_max` больше 64 — `nginx -t`: бюджет сообщения
- `waf_action_max` меньше 64 — `nginx -t`: короче кода повода
- незнакомый `do`, незнакомый `apply` или несовместимая пара — ответ
  отброшен целиком, как битый
- незнакомый адресат — действие отброшено, счётчик, лог
- адресат объявлен, но не на этом маршруте — действие живёт
- `delta` вне −1000…1000, `value` вне 0…1000 — ответ отброшен
- `from` / `phase` / `wave` с провода — отброшены молча:
  их ставит модуль
- внутренний редирект в location с меньшим пределом — режет
  при записи, уже доставленное не отзывается
- `mode=passive` — записи в `prior` нет вовсе: ни вердикта, ни
  действий. В аудите они есть, помечены недоставленными
- своих записей инспектор в `prior` не получает
