# waf

Главный выключатель. `off` — модуль ничего не делает, включая
локальный слой. `on` без сокета агента — `nginx -t`.

```
waf on|off;
```

Контекст: `http`, `server`, `location`, наследуемая.  
Умолчание: `off`.

```nginx
http {
    waf_agent_socket /run/waf/verdict.sock;
    waf on;                          # весь http

    location /health {
        waf off;                     # здесь пусто
    }
}
```

# страницы проверки: не `off`, а `on` без инспекторов

Страница капчи и форма входа не должны спрашивать инспекторов — иначе
капча требует капчу. Выключать ради этого модуль целиком не надо:
`off` снимает и локальный слой, а он там нужен — забаненный правилом
самой капчи адрес иначе молотит по генерации заданий, а отменённая
сессия ходит на форму.

```nginx
location ^~ /waf/captcha {
    waf on;
    waf_inspect request none;        # рекурсии нет
    waf_archive request none;        # архив страницы проверки не нужен

    waf_local_check cap_ipban $binary_remote_addr action=block response=blocked;
    waf_local_rate  $binary_remote_addr rate=10r/s burst=10 response=too_many;

    proxy_pass http://captcha-http;
}
```

# без инспекторов маршрут пишет журнал

Спрашивать некого — не значит молчать. Запись агенту уходит на каждой
фазе, которую маршрут велит записать, и инспекторы для этого не нужны:

- **запрос** — `waf_preview request` берёт срез из самого запроса (тело
  дочитывается, если его превью названо), `waf_archive request` кладёт
  объекты в обменник после прохода: в размере архива, со списками снимка
  (`mask=` у `waf_capture` действует), с `reload` — оригиналом;
- **ответ** — при `waf_preview response` / `waf_archive response` ответ
  уходит клиенту сразу, ничем не удерживаясь; в запись и архив идёт копия
  префикса тела (не больше `waf_body_limit response`) и заголовки. Запись
  фазы ответа уходит по концу ответа, а если ответ оборвался — с тем, что
  успели снять;
- **кадры** — итог сессии (`phase=session`) пишется при любой политике
  `waf_audit_frames`, кроме `off`; при `all` — ещё и каждый кадр со срезом,
  превью и архивом ([frame.md](frame.md#без-инспекторов)). Кадр уходит
  получателю, не дожидаясь записи.

Страницам проверки архив обычно не нужен — его снимают явно, как в примере.

# правила

- `on` требует `waf_agent_socket` в `http` — иначе аудит и preview
  никуда не уезжают, а конфиг выглядит пишущим
- `off` на location перекрывает родителя целиком
- шина, обменник, зона — отдельные директивы, этот флаг их не заводит
- `on` без инспекторов — обычный маршрут: тело запроса доезжает до
  апстрима, как при `off`. Выбрасывается оно только там, где отвечает
  сам модуль (отказ, редирект, сорванная политика)
