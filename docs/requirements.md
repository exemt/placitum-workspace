# Обязательные требования контроллера

Правила ниже — не рекомендации. Новый маршрут, клиент или агент, который им не следует,
не принимают.

## URI

Каждый URI конфигурации начинается с UUID пространства:

```
/api/<scope_uuid>/<resource>
```

`scope_uuid` — первичный ключ `http_spaces`. Это не имя (`default`), не query и не поле тела.

Примеры:

```
GET  /api/3f2a9c1e-4b2a-41c0-8f3a-000000000001/datasets
POST /api/3f2a9c1e-4b2a-41c0-8f3a-000000000001/datasets/…/addresses
GET  /api/3f2a9c1e-4b2a-41c0-8f3a-000000000001/store/<uuid>/blob
PUT  /api/3f2a9c1e-4b2a-41c0-8f3a-000000000001/rule-sets/<uuid>
```

Запрещено:

- `/api/datasets`, `/api/store`, `/api/rule-sets` без пространства;
- `?space=<uuid>` и `http_space_id` в теле вместо сегмента пути;
- имя пространства в пути (`/api/default/datasets`).

Несуществующий UUID пространства — `404 { "error": "unknown_scope" }`.
Строка, которая не UUID — `400 { "error": "invalid_scope" }`.
Объект другого пространства по этому префиксу — `404 { "error": "not_found" }`, без намёка,
что uuid живёт в соседнем контуре.

Исключения, не конфигурация пространства:

| URI | Зачем |
| --- | --- |
| `GET /healthz` | healthcheck процесса |
| `GET /api/health` | процесс + `select 1` к базе |
| `GET /api/meta` | снимок процесса для UX |
| `GET /api/spaces` | каталог пространств: без него UX не узнает uuid для scoped URI |
| `GET /api/fleet` | живые агенты, воркеры и инспекторы из Redux (последний healthup), не конфигурация |
| `GET /agent_health_socket` | WebSocket того же снимка; не REST |

Новый ресурс (серверы, пути, `send`, crypto) добавляют только под `/api/<scope_uuid>/…`.

## raw

На пространстве, сервере и пути есть флаг `raw` и поле `raw_nginx`. Это не
«довесок в конец файла», а замена внутренностей блока.

| Уровень | Скелет, который остаётся | Что заменяет raw |
| --- | --- | --- |
| пространство | сам `http {}`, каталоги в API | тело `http {}`; серверы и пути не печатаются |
| сервер | `listen`, `server_name`, сертификаты | тело `server {}`; пути и оверлеи не печатаются |
| путь | `location` match и path | тело `location {}`; handler, апстрим, оверлеи не печатаются |

Правила:

- `raw=false` — генератор печатает дерево (`nginx` + `waf` + дети). `raw_nginx` игнорируется.
- `raw=true` — генератор печатает скелет, затем текст как есть. Структурированные `nginx`/`waf` этого блока не печатаются. Дети в базе не удаляются и не едут в шаблон.
- Родитель с `raw=true` глушит детей при печати: raw сервера не печатается, если raw пространство; raw пути — если raw сервер.
- В `raw_nginx` нельзя `BEGIN PRIVATE KEY` / `BEGIN RSA PRIVATE KEY`: секреты только `store:<uuid>`.
- `map`, `geo`, `if`, lua, кэш, `include` произвольного файла — только через raw, отдельных полей под них нет.
