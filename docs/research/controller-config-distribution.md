# Контроллер как хранилище конфигурации nginx

## Вопрос

Как развезти конфигурацию nginx и чувствительные файлы на флот, не отдавая секреты контроллеру и
не укладывая тела в кадр NATS.

Спецификация принятого поведения — [config-distribution.md](../config-distribution.md). Здесь —
почему не другие упаковки.

## Короткий ответ

Принято: шаблон со ссылкой `store:<uuid>`, ciphertext в Postgres (`store_objects`), ключ контура
в Secret ноды, `send` манифеста в KV, `config_hash` по шаблону до подстановки. Агент забирает
объект `GET /api/<scope_uuid>/store/<uuid>/blob`, собирает дерево, `nginx -t`, `reload`.

## Что отвергнуто и почему

**Один tar.zst со всеми PEM в NATS Object Store.** Секреты оказываются в шине рядом с аудитом.
Контроллер как редактор всё равно должен их где-то держать. Object Store не даёт шифрования на
фронте без того же конверта, что уже есть у blob в Postgres.

**JSON с файлами в одном значении KV / один `PUB`.** `max_payload` 1 МБ общий с горячим путём.
Поднимать его нельзя, см. [body-storage.md](../body-storage.md#inline). Base64 раздувает PEM на
треть.

**Идентификатор = sha256 plaintext.** Контроллер тогда либо знает содержимое, либо не может
проверить ссылку. UUID — указатель; целостность тела — AEAD и ключ контура. Нода и так вычитывает
UUID из шаблона.

**`${store:…}` с долларом.** Совпадает с переменными nginx и с `envsubst`. Токен `store:<uuid>`
агент заменяет до `nginx -t`; мастер переменную не видит.

**Свой ключ на каждую ноду.** 101-й узел не откроет старые объекты: plaintext в контроллере нет,
rewrap без живой ноды не из чего. Ключ в Secret контура это закрывает ценой «слили ноду — слили
store».

**Ciphertext в S3 или Redis.** Лишняя зависимость и учётные данные на ноде (или presign). Объекты
мелкие, уже зашифрованы браузером, а источник правды для шаблона — Postgres. Агент ходит в тот же
API контроллера, что отдаёт поколение.

**Раздача тел из памяти процесса контроллера, без Postgres.** Рестарт в середине `send` оставляет
половину флота без объекта. Blob в `store_objects` это закрывает: контроллер — витрина, ряд
переживает процесс. Простой API во время apply всё ещё останавливает новое поколение; уже
скачанные файлы на ноде не пропадают.

## Что осталось вне спецификации

Операционный ритуал ротации Secret контура (rewrap живой нодой или повторная загрузка файлов) —
практика выкладки, не схема. Fingerprint публичного ключа при деплое контроллера — из того же
Secret, публичная половина.
