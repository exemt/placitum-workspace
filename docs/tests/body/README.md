# body — хранилище заголовков и тела

Единственный обменник контура (`waf_store`, Redis): два ключа, предел размера и то,
что после вердикта ключей в Redis не остаётся. `hot` в локаторе — ярус, а не имя
экземпляра: выбирать обменник на маршруте больше нечем, а отличать «лежит в
горячем» от «уехало в архив» читателю записи по-прежнему нужно.

```sh
cd deploy
docker compose exec -T nginx-1 sh /t/body/body.sh
```

`modsec` читает Redis: одно и то же тело с «union select» даёт 403
и на `/body/inline/`, и на `/body/store/`. Размещение видно в debug:
`body=hot:redis/…` и `headers=hot:redis/…`.

Считаются только ключи этого узла (`edge-01:`). База на стенде общая, и пульс
инспектора правил кладёт в неё свои `probe:*`: их уборка — не то утверждение,
которое проверяет этот прогон.

Последняя проверка — архивация на `/body/archive/`: владение ключами переходит
агенту, он кладёт тело в `waf-bodies` и заголовки в `waf-headers`, после чего
снимает оба ключа в Redis.

Что при этом доехало до шины — в [tests/audit](../audit/README.md): отсюда
`WAF_AUDIT` не видно.
