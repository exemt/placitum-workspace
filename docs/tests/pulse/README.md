# pulse — полный кадр присутствия

Контроллер разбирает `io`, `errors`, `waf`, `bus`, `host.disk` и `work.lag`,
UX их рисует, а новые секции производители ещё не пишут:
[docs/messages/fleet-pulse.md](../../messages/fleet-pulse.md). Это фикстура,
чтобы карточки было на чём смотреть: вердикты с fail-open, блок ошибок, диск,
флап шины, отставание логгера, eviction Redis (растущий `evicted` даёт
контроллеру дельту). У инспекторов в кадре есть и `config_hash`/`rev`, так
что сходимость правил (drift) тоже видна.

```sh
cd deploy
docker compose exec -T nats-box sh /t/pulse/pulse.sh once   # один кадр каждого вида
docker compose exec -T nats-box sh /t/pulse/pulse.sh        # поток, пока не прервут
```

Кадры уходят за пять видов сразу — агент, инспектор в двух репликах, Redis,
S3, сервис, — потому что форма канала одна на все, и проверять её надо на всех
карточках сразу. Участники свои, с приставкой `io-`: перебивать кадры
настоящих нельзя, они придут через свои четыре секунды и затрут фикстуру.
После остановки контроллер уберёт их через минуту тишины.

`EVERY` задаёт период публикации, `WINDOW` — объявленное окно в кадре.
