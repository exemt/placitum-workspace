# Витрина — защищаемое приложение стенда

Обычный апстрим за модулем. Про контур не знает ничего: вердиктов не выносит,
себя не закрывает, полезную нагрузку не исполняет. Единственная уступка стенду —
предсказуемость: набор выводится из номера карточки, поэтому после перезапуска
приложение отдаёт те же данные, те же метки и ту же пагинацию.

**Приложение честное.** Присланное отражается в ответ, чтобы было видно, что
запрос дошёл до апстрима, но SQL не исполняется, шаблон не раскрывается, диск не
читается. Предмет проверки — вердикт контура на этой нагрузке, а не дыра в
приложении. Дырявых полигонов (DVWA, Juice Shop) на стенде больше нет.

```sh
cd testapp && npm install && npm start     # локально, порт из .env (8099)
docker compose -f ../deploy/docker-compose.yml up -d app
```

## Чем кормится каждый инспектор

| Инспектор | Поверхность |
| --- | --- |
| **ip** | любой маршрут |
| **modsec / CRS** | `GET /catalog?q=`, `POST /api/search`, `POST /upload` (multipart), `GET /files?name=` |
| **auth `local`** | `/account` — закрывает калитка, приложение показывает `X-WAF-User` и `X-WAF-Groups` |
| **auth `app`** | `POST /api/login` → кука `sid` + `{"ok":true}` 200; `POST /api/logout` → тело, **не 204**; закрыто `/profile` |
| **auth `jwt`** | `POST /api/token` → RS256; `GET /keys/jwt.pub` — публичный ключ; закрыто `/api/private/me` |
| **gate.groups** | `/admin` — нужна группа `admins` (она есть у `bob`) |
| **captcha** | `/catalog` под корзинами просмотров, `/item/:id` — форма виджета телом (inline) |
| **json** | `/api/**` по контракту `/openapi.json`; `?broken=1` ломает **ответ** под этой же схемой |
| **counter** | метка `obj=<id>` — ровно одна на карточку; `per=12/24/48` меняет выдачу вчетверо |
| **vlai** | `POST /api/review` — свободный текст |
| **action** | префиксы `/api/`, `/admin/`, суффикс `.js`, статика `/static/` |
| **rewrite** | блоки и метки ниже |
| **фаза кадров** | `/socket/chat` (c2s→s2c, текст/JSON/бинарь/крупный), `/socket/feed` (только s2c) |
| **тело, обменник, архив** | `POST /api/bulk`, `POST /upload`, `GET /big?kb=N` |
| **отладка всего** | `GET /whoami` — заголовки целиком, сессия, притязания токена |
| **прогоны e2e** (`tests/load`, `tests/logic`) | `/load/**` и `/logic/**` любым методом — `{ok:true}`, путь и число байт тела; ничего не разбирает. `?objects=<n>` (до 200) добавляет выдачу штуками: у каждого объекта метка `obj=<id>` ровно один раз (по ней считает счётчик) и `canary-…` рядом (по ней видно работу модификатора). Без параметра ответ прежний байт в байт |

## Опоры для модификатора

Расставлены парами «цель и контроль»: если контроль пропал вместе с целью,
правило бьёт шире, чем написано, — и это ошибка правила, а не приложения.

| Опора | Где | Зачем |
| --- | --- | --- |
| `<!-- waf:ads -->…<!-- /waf:ads -->` | каждая страница | цель `remove` |
| `<!-- waf:keep -->…<!-- /waf:keep -->` | каждая страница | **контроль**: обязан выжить |
| `<!-- waf:anchor:head -->` | перед `</head>` | якорь `insert_before` / `insert_after` |
| `<!-- waf:anchor:body -->` | перед `</body>` | второй якорь, ниже по документу |
| `canary-<8 hex>` | HTML, JSON, кадры сокета | цель `replace` → `masked-$1` |
| `4111 1111 1111 1111` | `/order/:id`, `/leak` | маскирование номера карты |
| `debug-token=…`, `secret-42` | `/leak` | вычистка служебного |
| заголовок `X-App-Secret` | все ответы | цель `unset` |

Метки устойчивы: `canary-` считается как `sha256("item:7")[:8]`, одинаково на
всех машинах и после перезапуска. Прогон может ждать конкретное значение.

## Учётные записи

| Логин | Пароль | Группы |
| --- | --- | --- |
| `alice` | `alice-pw` | `users` |
| `bob` | `bob-pass` | `users`, `admins` |

Лежат в git открытым текстом намеренно: это фикстура стенда. Свои учётки калитки
(провайдер `local`) живут не здесь, а в наборе данных контроллера — приложение о
них не знает вовсе.

**Ключ RS256 генерируется на старте.** Секрета в репозитории нет, но публичный
ключ меняется на каждый перезапуск, и источник входа `jwt` после него надо
перенастроить с `/keys/jwt.pub`. Чтобы ключ пережил рестарт — `APP_JWT_PRIVATE_KEY`.

## Чего приложение НЕ делает

- не пишет на диск (`/upload` считает размер и sha256, файл выбрасывает);
- не читает диск (`/files` отражает имя и отвечает «не отдано»);
- не ходит в базу — набор целиком в памяти;
- не закрывает `/account` и `/admin` само: напрямую, в обход контура, они
  открыты. Иначе проверялось бы, что приложение умеет закрывать себя, а не что
  калитка стоит на маршруте.

## Переменные

| Переменная | Умолчание | Что делает |
| --- | --- | --- |
| `PORT` | `8080` | порт |
| `APP_NAME` | `shop` | имя в журнале и в `X-App-Name` |
| `APP_LOG` | `info` | `debug` показывает кадры сокета |
| `APP_ITEMS` | `120` | размер набора; меняет пагинацию |
| `APP_MAX_BODY_BYTES` | `16m` | потолок тела запроса |
| `APP_MAX_BIG_BYTES` | `8m` | потолок `/big` |
| `APP_SESSION_TTL_S` | `28800` | срок куки `sid` |
| `APP_TOKEN_TTL_S` | `900` | срок токена |
| `APP_JWT_PRIVATE_KEY` | — | PEM; пусто — пара генерируется на старте |
| `APP_FEED_INTERVAL_MS` | `1000` | как часто `/socket/feed` шлёт кадр |
| `APP_MAX_FRAME_BYTES` | `1m` | потолок кадра; крупнее — закрытие с 1009 |
